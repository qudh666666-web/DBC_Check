v3.0.8
- E2E ID表支持一个工作表内多路 TX/RX + DATA ID 列组，例如 TX1/DATA ID、RX/DATA ID、TX2/DATA ID。
- Excel中如检测到多个可识别E2E工作表，默认新增“全部可识别工作表”选项并汇总导入。
- 无关工作表会在“全部”模式下自动跳过，不影响检查。
- 客户E2E表可以只提供部分SignalGroup；DBC里客户表未列出的E2E组默认不判错误。
- SignalGroup已给出但Data ID为空或“-”时仅提示并跳过数值核对。
- 同一SignalGroup跨工作表/多路配置相同Data ID会自动去重；配置不同Data ID时仍报客户表冲突，并标注工作表和行号来源。
- 查看E2E映射时显示来源工作表/行号信息，多工作表表头不一致时显示“各表自动识别”。
