CAN矩阵-DBC一致性检查工具 v3.0.7

1. “查看E2E映射”由简单表头提示改为完整核对表格：
   - 方向（TX/RX）
   - 客户SignalGroup / DBC SignalGroup
   - CAN ID十六进制 / 十进制
   - 报文名称
   - 客户DataID十六进制 / 十进制
   - DBC DataID十六进制 / 十进制
   - 结果与说明
2. E2E映射窗口增加一致、不一致、缺失/冲突、客户未给ID的汇总统计。
3. 主结果区增加“类型”筛选，与原“级别”筛选可组合使用：
   - DBC自身/规则
   - 矩阵差异
   - E2E全部
   - E2E DataID表
   - E2E DataLength
   - NM
   - UDS/诊断
   - XCP
4. 筛选后没有命中项时，结果区明确显示“当前筛选条件无匹配项”，避免误以为程序卡住。
5. 不改变v3.0.6的DBC判断规则和E2E一键修改逻辑。
